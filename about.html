About This Project & Its Creator

Hi! My name is Niamh, and this website was created as my final project for SI 339. I chose to build a dynamic site focused on The Weeknd's discography. Since each album has such strong visual identity and thematic style, this made it a fun challenge to create design changes for each album using JavaScript.

What I Wanted to Learn

Going into this project, I wanted to learn how to use JavaScript to update content dynamically. I also aimed to become more comfortable using embedded media, such as Spotify albums, and storing content in structured data objects.

Design & Visual Choices

Each album changes the site's colors, images, and embedded music player. I wanted users to feel immersed in the mood of each record without overwhelming them visually. That meant choosing a simple layout with a sidebar for album selection and giving each album a unique personality through color accents and visuals.

Accessibility as a Priority

Accessibility was a major focus throughout this project. I implemented skip links, keyboard-accessible buttons, semantic HTML structure, descriptive alt text, and autism friendly layout.

Challenges & What I Learned

I learned how to use ARIA labels correctly to ensure accessibility for all users. My main challange was keeping the page fully accessible before and after updating content. I had to make sure there were no hidden headings when the page first loaded so that the semantic HTML structure was kept intact.

Final Thoughts

This was one of my favorite projects to build, and it helped me gain confidence in both design and development. I hope to continue exploring interactive UI design and deeper accessibility practices in future projects. Thanks for visiting my site!
